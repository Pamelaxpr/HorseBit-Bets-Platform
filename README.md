# Simulator-Real-Time-Horse-Racing-Platform
Horse racing Bets platform with a Simulator in "Real-time" tracking, hybrid cloud/edge architecture, MQTT, and sensor simulation.

Structure:
tfg-presentacion/
├── assets/                  -> Recursos multimedia y capturas
│   ├── uni-logo.jpg         (Logo de la universidad / unilogoo.jpg)
│   ├── project-logo.png     (Logo del proyecto / hipoant.png)
│   ├── qr-code.jpeg         (Código QR / qr.jpeg)
│   ├── screenshot-page.png  (Captura de pantalla de página / pag.png)
│   └── screenshot-web.png   (Captura de pantalla de la web / web.png)
├── css/                     -> Hojas de estilo
│   └── main.css             (Estilos globales / css.css)
├── js/                      -> Scripts de lógica y utilidades
│   └── export-pdf.js        (Script para exportar la presentación a PDF)
├── views/                   -> Subvistas o módulos interactivos
│   ├── mqtt.html            (Módulo/demostración MQTT)
│   └── qr.html              (Módulo/demostración QR)
├── index.html               (Presentación principal / presentacion.html)
├── package.json             (Configuración de dependencias npm)
├── package-lock.json        (Bloqueo de versiones npm)
├── .gitignore               (Archivos a ignorar por Git)
└── README.md                (Documentación del proyecto en inglés)
